## About Me

I'm Alex, a SysAdmin & Cybersecurity Student. Passionate about Linux, network security, and automation. This repository contains all my class projects, lab reports, and scripts developed during my studies. I intentionally structure my documentation and lab reports as step-by-step guides. My goal is that any fellow student or IT enthusiast with a similar skill level can use them as hands-on tutorials to follow along and learn with me.
